# The Extra Window

One original one-line horror sentence for the
[make.fun One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488)
bounty.

## The line

> Every photo I take of my house now shows one extra window, and last night it was lit from inside.

## How it works

`main.py` (Python 3.13, standard library only) writes that one line — 97
characters, inside the 1–200 character gate — to `/output/entry.txt`. No
network, no randomness, no input: every run writes the exact same bytes, and
the program reads the file back afterwards to prove it matches.

## Why this line

It was picked by pre-judging eight original candidates pairwise, in both
orders, against the horror-editor brief published in the kit. The exact judge
model (z-ai/glm-5.3-flash on OpenRouter) was unreachable — the account's
purchased credits are exhausted (HTTP 402) and the `:free` variant returns
404 — and the Gemini free tier was rate-limited (HTTP 429), so the rounds ran
on a free proxy model (AMD TokenLab DeepSeek-V4-Flash, free allowance, no
money spent). "The Extra Window" won the eight-way round-robin with a 0.614
mean game score, taking its games against the council-letter line 0.85 and
the lift line 0.90, and none of the three fresh challengers in a second round
beat it. Against the strongest lines already on the bounty feed it is
honestly mid-field — it tied the baby-monitor lullaby line, lost narrowly to
the whispered-goodnight line, and lost clearly to the daughter's-drawings
line — so this is a solid entry, not a guaranteed winner. The scare is
withheld rather than announced: an ordinary act (photographing your own
house), a wrong detail that keeps happening, and a last clause that makes the
wrongness look back at you.
